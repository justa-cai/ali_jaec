ali_jaec

04 指标

500 个留出测试文件（每个 10 秒）。SI-SDR 对照干净近端语音计算： 它是唯一能同时惩罚「残留回声」和「削掉近端」两种失败的单一数字。

「远端静音段保持度」是远端不说话时输出与麦克风的能量比：0 dB 表示原样通过， 负值表示近端被削。设这一项是为了防止「把所有东西都衰减掉」也能拿高分。

05 怎么做的

ref  x(n) ─┬─> [ 延迟估计 ]  GCC-PHAT 互相关 → soft-argmax
           │        │  tau
           │        v
           │   对齐参考  x_tau(n)
           │        │
mic  d(n) ─┼────────┴─> [ 回声估计 ]  逐频点因果 FIR
           │                    │  y_hat(n)
           │                    v
           │          最小二乘增益  alpha = <Xm, y_hat> / <y_hat, y_hat>
           │                    │
           └─────────> e(n) = mask( d(n) - alpha * y_hat(n) )
  • 延迟估计。GCC-PHAT 互相关经可微 soft-argmax 得到一个标量延迟， 据此对齐参考信号。下游就只需要处理趋近于零的残余延迟。
  • 回声估计。在帧间做因果 FIR，每个频点每个抽头一个复权重。
  • 最小二乘增益。回声估计只依赖参考信号，所以远端一响它就非零—— 哪怕麦克风里根本没有回声。此时减掉它会把远端注入输出。 增益 <Xm, y_hat> / <y_hat, y_hat> 衡量这份估计究竟解释了多少麦克风能量， 有回声时趋近 1，没回声时趋近 0。
  • 掩码。GRU 在 16 个频带上预测谱掩码，对残余做整形。

没有非线性处理级：被消除的始终只是参考信号的线性函数。 麦克风侧的非线性（例如参考信号看不到的削波）无法恢复。
